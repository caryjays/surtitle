# Decisions

Verified: 2026-10-28 · Sources: none

Append-only, newest last. To reverse a decision, add a new entry and mark the old one superseded.

| Date | Decision | Why |
| --- | --- | --- |
| 2026-10-18 | One Node process, one loopback origin, esbuild-bundled plain TypeScript, no UI framework, Zod at every boundary | Fewest moving parts for a one-operator tool |
| 2026-10-18 | The browser AudioWorklet resamples to 24 kHz PCM16 in 50 ms frames; MediaRecorder is not used | Provider PCM contract and exact timing control |
| 2026-10-18 | Service-side energy VAD with 700 ms quiet, 12 s cap and 300 ms pre-roll; turns are transport boundaries | Bounded, testable, provider-independent |
| 2026-10-18 | Identity model: session UUID, display generation, monotonic sequence, epoch for translation jobs; late results only update their own row | Prevents stale or reordered captions |
| 2026-10-18 | Cloud providers for the first slice: `gpt-live-transcribe` over Realtime with local commits, and `gpt-5.6-terra` over Responses with strict JSON and `store: false` | Current provider documentation; deprecated minis avoided. Cloud recognition has never run live |
| 2026-10-18 | Loopback bind, exact Host and Origin, CSP, single control owner, read-only overlays, no secret in the browser | Local hosting does not excuse open access |
| 2026-10-21 | Local-first: MLX Whisper in an isolated stdio Python worker behind the existing `Transcriber` seam, with no provider framework | Local recognition became a hard requirement after a venue run on shared Wi-Fi |
| 2026-10-21 | Turbo Q4 over Small Q4; keep the 12 s cap | Better EN WER and JA CER on the tuning set; 6 s and 8 s caps hurt Japanese |
| 2026-10-21 | `dev:local` and `start:local` never load `.env`; every launch defaults to local recognition with translation off | No paid stage by accident |
| by 2026-10-24 | Listen profile: local recognition plus cloud translation; Conversation is per-turn auto, Lecture is `ja-en`; a preset change commits the current turn with its old hint; no session cap for local; 60-row history; four-row frozen context; previews need two agreeing hypotheses | Personal lecture and conversation use before OBS |
| by 2026-10-24 | Silence fix: CPU Silero gate before Whisper, 1.5 s room calibration, browser AGC off, glossary no longer injected into Whisper, repetition rejection in worker, adapter and controller | The first physical-microphone test hallucinated in silence and fed paid translation |
| by 2026-10-24 | Diagnostics are opt-in, content-free, schema-bound and browser-held until explicit download | Field debugging without retaining anyone's speech |
| after 2026-10-24 | Version-2 turn telemetry: per-turn boundary, timing, language, filter and translation metadata through a strict `TurnTrace`, with no behavior change | Version-1 logs could not separate splitting from loss |
| after 2026-10-24 | The reader renders only on caption changes and reuses the network-validated snapshot | Sluggishness was reported after the telemetry upgrade |
| 2026-10-26 | Noisy-Japanese experiment: no live default changed | Lower thresholds matched baseline; faster previews did not speed finals; an 8 s cap hurt CER |
| 2026-10-26 | Documentation split into a present-tense wiki and a dated log, with `pnpm docs:check` inside `pnpm check` | Stacked dated sections across twelve files went stale and contradicted each other |
| 2026-10-26 | The repository is public by default under Apache 2.0; personal context lives only in the ignored `private/` overlay, which agents read after the tracked `AGENTS.md`; the glossary resolves to the private file when present and to a tracked generic example otherwise | One codebase keeps a public profile current without porting; a scrubbed fork would rot |
| 2026-10-26 | `pnpm docs:check` scans every commit-eligible file for leak patterns and a private denylist, and refuses links from public docs into `private/` | A future session log is the likeliest place for a private detail to slip |
| 2026-10-26 | Project named Surtitle, the theatre term for live translated text above a stage | Language-neutral so other language pairs can follow; descriptive of live-event use; no competing software uses the name and the npm, PyPI and GitHub names were free |
| 2026-10-26 | Second cloud translator: Anthropic Messages behind `TRANSLATION_PROVIDER=anthropic`, default model `claude-haiku-5-5`; OpenAI Terra stays the default | Haiku 5.5 lists at a small fraction of Terra's price and supports schema-forced JSON. Promoting it needs a controlled comparison first. The adapter uses the official SDK with retries off; its separate model variable keeps an existing Terra `TRANSLATION_MODEL` from being sent to the wrong provider |
| 2026-10-26 | Translation models are compared with a reusable replay eval: frozen public recognizer output, required-term checks, a model judge against the reference, sequential warm latency, and token cost; paid calls only with `--paid` | One command answers "is model X faster or better than the default" for any future cloud or local model; a frozen case file keeps runs comparable across time |
| 2026-10-26 | Local and private-network translators plug in through OpenAI-compatible chat completions, eval-only for now | mlx_lm.server, LM Studio and Ollama all speak it, so candidate local models need no new adapter; the live fallback design stays deferred per the roadmap |
| 2026-10-26 | Captions favour a smooth reading pace over minimum delay: the audience sees settled text released at a reading rate, never bursts or rewrites; no fixed maximum delay | The maintainer's experience of caption readability; bursty delivery is harder to read than steady lag. Simulation: pacing caps release at about 28 EN or 11 JA characters a second for a few seconds of added lag |
| 2026-10-27 | Identity: a local-first, presenter-controlled caption layer, published as open source and used by the maintainer; closed productization, hosting, accounts and paid tiers are out of scope | The tool and the public repository support each other; a closed product needs business development the project cannot justify, and hosting would undo local recognition |
| 2026-10-27 | One bilingual pair per session, English with one other language; Japanese first; then Spanish, French and Italian, Chinese Simplified and Traditional, Korean, German. Supersedes treating EN ↔ JA as the whole product | The maintainer's audience values these languages; a fixed pair keeps automatic direction and the two overrides meaningful |
| 2026-10-27 | Generalize the language pair in the protocol and per-language profiles before adding any language, as a separate change after the rolling replay | Two hardcoded languages are cheap to generalize while one pair has tests and fakes; costly once several do |
| 2026-10-27 | A new language ships only after a written gate: public fixtures, held-out targets set in advance, a stock-phrase sweep and a translation eval; Japanese also needs a clean field session | Adding a language is mostly building its evaluation; criteria set before the run keep the decision honest |
| 2026-10-27 | Stay with TypeScript for the service and Python for the recognition worker; no Rust rewrite and no native OBS plugin; OBS control goes through obs-websocket | Measured decode time is GPU-bound and the remaining delay is turn boundaries and network; a plugin would tie capture to the OBS process; MLX models appear in Python first |
| 2026-10-27 | Usage is described as five lanes, Remote call, Hosted stage, Direct stage, Open floor and Audience seat, each defined by audio source and caption target | Source and target decide the capture settings; named lanes become recommendable presets |
| 2026-10-27 | Source profiles, Close mic, Line feed, Far field and App audio, replace the planned on/off toggles for browser echo cancellation and noise suppression | Fixed flags suit only a close microphone and are the leading hypothesis for open-floor false rejection |
| 2026-10-27 | A source identifier goes on frames, traces and rows now; two simultaneous sources, each with its own direction hint, come after the Japanese gate. Supersedes deferring remote call audio, echo and deduplication as one problem | Separate streams with a known language avoid echo cancellation and cross-source deduplication and reduce language drift |
| 2026-10-27 | Every input is a macOS input device Chrome can open, including an iPhone through Continuity and a virtual loopback device; no network microphones or LAN phone readers | The project is macOS only, so Continuity covers the phone; LAN exposure adds HTTPS and an approval boundary for little gain |
| 2026-10-27 | Horizon for languages: through the medium term, only pairs with English, one per session; several languages per session or non-English pairs stay a long-term possibility, not designed for now | The maintainer expects model improvements to make more complex setups achievable later; designing for them now would slow the English pairs |
| 2026-10-27 | Rolling recognition locks whole Whisper segments; locking single words once two decodes agree was measured and rejected | Word locking raised held-out error from 1.4% to 2.6% in English and from 3.9% to 6.2% in Japanese for text about 1 to 3 s sooner, because later decodes often correct the first agreed words |
| 2026-10-27 | Merging short pause-closed rolling rows is deferred until rehearsal | The held-out replay produced only 2 such rows in 176; lectures pause more than the recordings, so rehearsal decides |
| 2026-10-27 | The language pair is configuration: `LANGUAGE_PAIR`, profiles in one `profiles/languages.json` read by Node and the Python worker, modes `auto` plus `source-target` directions, schemas that accept any language code while the controller enforces the pair, and Lecture as the other language into English | One file keeps both runtimes' rules in step; unchanged mode strings keep the wire format, diagnostics and the en-ja translation prompt identical, so existing evals stay comparable |
| 2026-10-28 | Japanese gate targets are fixed in [gates](gates.md) before any gate run: held-out live CER at most 5.0% with deletions at most 2.0%, English WER at most 4.0% with deletions at most 1.0%, public FLEURS limits plus at most 1.5 points over the full-clip decode, no displayed text on non-speech, translation fidelity of at least 4.3 under two judges on correctly recognized inputs, and one field session without capture failure | Targets sit just above the rolling replay on silver references, so they demand that rolling hold on new material rather than improve on it. The seven recordings behind the rolling design are excluded, because they informed it |
| 2026-10-28 | Gate streams level-match every public and non-speech clip to a 90th-percentile 50 ms RMS of 0.1 before replay; held-out recordings keep their level | 40 of the 60 English gate clips sit below the live gate's 0.004 floor, so unscaled they measure faint input, which is open problem 1 with its own sweep, rather than segmentation. Scaling non-speech to speech level makes the hallucination check stricter, since the gate opens and Silero and the filters must reject it |
| 2026-10-28 | Long development runs come from YODAS2's CC BY 3.0 subsets with uploaded subtitles, fetched from the pinned dataset, with an agent-reviewed exclusion list kept in `private/`; nothing is downloaded from YouTube directly and JTubeSpeech is not used | The dataset gives licensed long-form speech without YouTube's download terms, while JTubeSpeech is a list of video IDs to download from YouTube. Automatic-caption subsets would score Whisper against similar machine output. Uploaded subtitles are not verbatim, so the corpus is for development and never for the gate |
| 2026-10-28 | Long and exploratory runs may run on a second, faster Mac; gate results that decide a default come from the target laptop | Real-time replay output depends on how many decodes fit in a second, so a faster or cooler machine locks text differently. The fanless laptop is the primary standalone target, and every run records its platform |
