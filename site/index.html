Make yourself

Run Surtitle from source. Start with local captions, then add translation when you're ready.

What you'll need

  • An Apple Silicon Mac
  • Node.js 22.9+, pnpm, uv, and ffmpeg
  • Google Chrome and a microphone
  • OBS, if you want an audience overlay

Initial setup downloads a few gigabytes of pinned models and public test fixtures. After setup, the local profiles run without a network connection.

Full setup & operating guide

  1. Install and run

    TERMINAL
    git clone https://github.com/caryjays/surtitle.gitcd surtitlepnpm installpnpm local:setuppnpm dev:local
    Local recognition · Translation off · No API key

  2. Open the operator console

    Once the service is running, open http://127.0.0.1:4317/control in Chrome on that Mac. Use 127.0.0.1; localhost is intentionally refused.

  3. Pick your input. Start speaking.

    Choose the language pair, click Start microphone, and allow microphone access when Chrome asks. Speak when the activity line says Listening. To use another input, pick it under the console's diagnostics section; device names appear once access is allowed. In the translation profiles, keep the room quiet through the 1.5-second noise calibration first.

Prefer cloud translation?

The explicit pnpm dev:listen profile uses paid text translation through OpenAI or Anthropic. Recognition stays local; speech-derived text goes to the selected provider. Configure your own key following the configuration guide, then run pnpm preflight:listen before starting. Paid requests begin after Start, for finalized speech.
